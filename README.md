# SRT 字幕时间校准工具

一个网页小工具：根据若干「原字幕时刻 → 视频实际时刻」锚点，对整份 SRT 字幕做时间校准。

- 后端：Python + FastAPI
- 前端：原生 HTML/JS 单页（无构建步骤）
- 校准算法：锚点按原时刻排序，相邻锚点间**线性插值**，首尾两端按**最近一段斜率外推**，统一换算每条字幕的起止时间

## 启动

只需一条命令（依赖随容器自动安装）：

```bash
docker compose up --build
```

然后在浏览器打开：

**http://localhost:8000** （端口 `8000`）

停止：`Ctrl+C` 或 `docker compose down`。

## 使用方法

1. **字幕内容**：粘贴 SRT 文本，或点击「选择文件」上传 `.srt` 文件。
2. **校准锚点**：至少填写 2 个锚点，格式为 `HH:MM:SS,mmm`：
   - 原时刻：字幕文件中显示的时间
   - 实际时刻：该句在视频中真实出现的时间
3. 点击 **预览校准结果**：表格逐条显示原时间、校准后时间及问题标记。
4. 全部正常时点击 **导出校准后 SRT** 下载 `calibrated.srt`（保留原序号与正文）。

## 规则说明

### 锚点校验（不满足会被拒绝并提示）

- 至少 2 个锚点；
- 原时刻不得重复；
- 映射后的实际时刻必须严格递增。

### 问题检测（存在任一问题时禁止导出）

| 问题 | 判定 |
| --- | --- |
| 负时间 | 校准后起点或终点 < 0 |
| 起止倒置 | 校准后终点 ≤ 起点 |
| 与下一条重叠 | 本条终点 > 下一条起点 |

前端预览会标红问题行，后端导出接口同样强制校验，有问题返回 400。

## API

- `POST /api/preview` — 请求体 `{"srt": "...", "anchors": [{"orig": "00:01:00,000", "actual": "00:01:02,500"}, ...]}`，返回逐条校准结果与问题标记。
- `POST /api/export` — 同上请求体；无问题时返回 `calibrated.srt` 文件下载，有问题返回 `400`。
